# 🕸️ Complex Networks

This repository contains the lab assignments and activities developed for a **Complex Networks** course. The work is organized using Python and Jupyter Notebooks, covering topics from network fundamentals all the way to community detection algorithms.

## 📁 Repository Structure

```
complex-networks/
├── labs/
│   ├── lab1/   # Network basics and representation
│   ├── lab2/   # Network structural characterization (Part I)
│   ├── lab3/   # Network structural characterization (Part II)
│   ├── lab4/   # Network models
│   ├── lab5/   # Community detection (Part I)
│   └── lab6/   # Community detection (Part II)
└── activities/
    ├── A1/     # Network structure and models analysis
    └── A2/     # Community structures analysis
```

## 🧪 Labs

| Lab | Topic |
|-----|-------|
| Lab 1 | Network basics and representation |
| Lab 2 | Network structural characterization (Part I) |
| Lab 3 | Network structural characterization (Part II) |
| Lab 4 | Network models (Erdős–Rényi, Barabási–Albert, etc.) |
| Lab 5 | Community detection (Part I) |
| Lab 6 | Community detection (Part II) |

Each lab folder contains:
- **Notebooks/** or root `.ipynb` files with the analysis and experiments
- **Datasets/** or **Data/**: Input graph data files

## 📝 Activities

Graded assignments that apply concepts from the labs to real-world network datasets.

- **A1 – Network Structure and Models**: Structural analysis and comparison of network models. Includes a written report (`report.pdf`) and a Jupyter Notebook.
- **A2 – Community Structures**: Detection and analysis of community structures in networks. Includes a written report (`report_A2.pdf`) and supporting code.

## 🛠️ Technologies

- Python 3
- [NetworkX](https://networkx.org/)
- Jupyter Notebook
- Matplotlib / NumPy

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/OmarMorales71/complex-networks.git
   cd complex-networks
   ```

2. Install dependencies:
   ```bash
   pip install networkx matplotlib numpy jupyter
   ```

3. Launch Jupyter:
   ```bash
   jupyter notebook
   ```
